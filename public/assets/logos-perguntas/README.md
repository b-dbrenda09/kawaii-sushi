# Logo das perguntas

Adicione sua imagem original nesta pasta com o nome exato `logo-perguntas.png`.
Não há imagem de exemplo: o jogo utiliza exclusivamente o arquivo que você adicionar.

- Caminho no projeto: `public/assets/logos-perguntas/logo-perguntas.png`.
- Endereço servido pelo Vite: `/assets/logos-perguntas/logo-perguntas.png`.
- Configuração centralizada: `CUSTOM_ASSETS.questionLogo` em `src/config/CustomAssets.js`.
- Exibição no topo do pop-up educativo, centralizada, com largura máxima de 240 px e altura automática.
- A imagem é mostrada inteira, sem distorções ou recortes. Prefira margens pequenas ao redor da arte.
- Se o arquivo estiver ausente ou inválido, o cabeçalho padrão permanece, sem imagem quebrada.

Recarregue a página após adicionar a imagem. Para publicar, execute `npm run build` novamente.
A logo do menu inicial continua na pasta `assets/logos-personalizadas` e não é alterada.
